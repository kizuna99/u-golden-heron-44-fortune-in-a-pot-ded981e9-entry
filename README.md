A one-line fortune for a houseplant, written by `main.py` to `/output/entry.txt`. The fortune speaks to one specific fern on one specific windowsill — the best sunbeam, a keeper so proud they buy it a name tag — in the cadence of a prediction, kind and funny, in a single clean line well within the 120-character gate. Run it with `python3 main.py` (set `OUTPUT_DIR` to redirect the output locally); it prints the fortune as it writes it.
